# jp-risk-radar（キーワード版）

やることは 1 つ：**言葉の出現頻度が自分の基線より増えているか**を見つけ、代表的な見出しと一緒に示す。会社名や銘柄への紐づけはしない。

## モード

| モード | 依頼の例 | 出力 |
|---|---|---|
| **热词** | 「最近什么话题在涨」「今日扫一下」「何か異変ある？」 | 増えている言葉の一覧（下の形式） |
| **深挖** | 「漏えい 这个词最近怎么样」「不正アクセス の時系列」 | 1 語の日別件数、初出、代表見出し、関連して増えている語 |
| **读取 radar** | GitHub の `state/latest.json` の raw URL を渡された | JSON を読んで 热词 形式で要約。自分で検索し直さない |

回答の言語はユーザーのメッセージに合わせる。見出しは原文（日本語）のまま。

## 热词モード（radar の出力が無いとき）

1. `references/sources.md` の媒体・クエリで直近 24h を WebSearch する。6〜10 回。社会・経済・IT を偏りなく。
2. 見出しから名詞・名詞句を拾い、同じ語が **異なる事案・異なる媒体** で何回出たかを数える。同一事案の続報は 1 回と数える。
3. 「その語は普段どれくらい出るか」を自分の感覚で見積もり、明らかに増えている語だけを出す。毎日出る語（政府・円相場・大谷翔平）は出さない。
4. 出力形式：

```
## 増えている言葉（24h）
🔴 高   不正アクセス   6 件 / 普段ほぼ 0   ← 焼肉きんぐ・ブックオフ・ローソン・JR東
🟠 上昇 漏えい         5 件 / 普段 1 前後  ← 同上 + 政府が事業者に要請
🟠 上昇 下方修正       4 件 / 普段 1 前後  ← 決算シーズン入り

## 代表見出し
- <見出し>（媒体 日付）URL
```

5. 最後に「増えている理由」を 1〜2 行。事実のみ、推測はそう書く。

## 深挖モード

その語で WebSearch（`<語> when:7d` を含む）→ 日別件数の表 → 初出の見出し → 最新 3 本 → 同じ見出しに一緒に出る語（共起語）を 5 個。「次に増えそうな語」は書かない。

## 读取 radar モード

`keywords[]` を level（high→rising→watch）、ratio の順に並べ、`days`（過去 7 日の日別件数）を `▁▂▃▅█` で添える。`generated` を冒頭に。⭐ は `data/watchwords.txt` の関注词。

## 継続監視を頼まれたら

15 分ごとの自動監視は GitHub Actions 版（同名リポジトリ）の仕事。README のセットアップ手順を案内する。この会話内で「毎朝」などと言われたら scheduled task を作り、prompt に「jp-risk-radar の 热词モードを実行し、前回より増えた語だけ報告」と書く。
